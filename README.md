# Minecraft GUI Studio

Editor visuale offline per GUI e inventari di Minecraft: disegni il menu a griglia con l'aspetto del gioco, lo validi e lo esporti come JSON, YAML, codice Java (Paper) e configurazione ItemsAdder. App gratuita per **Windows 10 e 11 (64 bit)**.

**[Scarica l'ultima versione](https://github.com/geniofabry-cell/MinecraftGuiStudio-download/releases/latest)**

- `Minecraft-GUI-Studio-Setup-x.y.z.exe`: installer (consigliato). Si aggiorna da solo.
- `Minecraft-GUI-Studio-x.y.z-portable.exe`: si avvia senza installazione (avvisa quando c'è una nuova versione).

Al primo avvio Windows può mostrare "Windows ha protetto il PC": clicca **Ulteriori informazioni → Esegui comunque** (l'app non ha una firma digitale a pagamento).

I dati restano sul tuo computer: l'app non ha account e non invia nulla a nessun server. Le texture di Minecraft, se le importi, vengono lette dalla tua installazione e non lasciano il tuo PC.

Problemi o domande? Apri una [segnalazione](https://github.com/geniofabry-cell/MinecraftGuiStudio-download/issues).
